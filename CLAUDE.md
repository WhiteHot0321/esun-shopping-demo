# Project instructions

## Always use the ADHD skill

For every user request in this repository, invoke the `adhd` skill
(`.claude/skills/adhd/SKILL.md`) before answering — skip its own
"Pre-flight" self-judge gate entirely and go straight to Phase 1
(Diverge) every time, even for simple, closed, or syntax-level
questions. Do not decide case-by-case whether the question "deserves"
ADHD mode; always run the full two-phase loop and render the full
output shape (Brief, Wide set, Converge, Focus, Provocation).
