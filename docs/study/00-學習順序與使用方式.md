# 學習提示詞：使用方式與順序

## 怎麼用
1. 每次開**新的 session**，只貼**一份**提示詞（從「提示詞開始」貼到檔案結尾）。
2. 一個 session 學完一個主題就結束，下一個主題開新 session，避免 context 被吃光。
3. 每份提示詞開頭的 `教學模式:` 會觸發 `learning-mentor`（見 CLAUDE.md），它會先問你、不直接給答案。
4. 每個 session 結束前，請它輸出「弱點表」，自己存下來。下一輪先複習弱點表。

## 檔案
| 檔案 | 內容 | 性質 |
|---|---|---|
| 01 | Java 語言與基礎（並發、交易、JVM、集合、Spring 核心） | 知識 |
| 02 | 框架與資料層（索引、N+1、JdbcTemplate/MyBatis/JPA、Spring Security） | 知識 |
| 03 | 你自己的專案（JWT、超賣、登入、冪等、Redis、Testcontainers） | 知識＋對照程式碼 |
| 04 | 工具與前端（Docker、Vue、OWASP） | 知識 |
| 05 | 模擬追問與表達習慣 | 反應訓練 |

## 建議順序（01 與 03 交錯，因為講的是同一件事）
- **第一輪（約 3～4 天）**
  1. 01 的 A 區「並發與鎖」＋「交易與隔離層級」
  2. 03 的「超賣」「冪等與鎖順序」
  3. 03 的「JWT」「登入流程」
  4. 03 的 Redis、Testcontainers
- **第二輪（約 2 天）**：02 → 04 → 01 的 JVM／集合／Spring 核心
- **貫穿全程**：每天最後 15 分鐘做 05 的模擬追問；面試前 2 天只做 05。

## 學習判斷標準
不看資料，用自己的話向不懂的人解釋「為什麼」。只能說「是什麼」就還沒學會。
