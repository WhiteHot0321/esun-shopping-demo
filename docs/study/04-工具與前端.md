   - 專案對照：`backend/Dockerfile:1,10`
4. **非 root 容器 vs rootless Docker**：兩者差在哪、各防什麼
   - 專案對照：`Dockerfile:23`（`USER spring`）、`docker-compose.prod.yml:122-127`（`cap_drop: ALL`、`read_only`、`no-new-privileges`）。**我專案實際做到哪一個？** `README.md:24` 的「無根容器」寫法該怎麼改才誠實？

## B 區：Vue 3
6. `ref` vs `reactive`：`.value`、整個重新指派、解構與 `toRefs`
